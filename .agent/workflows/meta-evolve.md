# 工作流：元学习 (/meta-evolve)

本工作流分析进化引擎自身的运行效果，学习"如何更好地学习"。

## 触发方式

- 手动: `/meta-evolve`
- 自动: 每 5 次 `/evolve` 自动触发

## 执行步骤

1. **知识价值分析**
   - 分析各类别知识的因果评分分布
   - 找出最有价值和最无价值的知识
   - 统计从未被应用的知识比例

2. **收割策略评估**
   - 分析当前收割策略的有效性
   - 识别过度收割或不足收割的类别
   - 建议调整收割优先级和阈值

3. **知识盲区检测**
   - 检查必要类别是否有足够知识支持
   - 分析工作流中哪些阶段缺乏知识注入
   - 识别参考项目学习的覆盖度

4. **进化规则调优**
   - 分析衰减速率是否合适
   - 分析注入 top-k 是否合适
   - 分析归档策略是否合适
   - 生成参数调整建议

5. **生成洞察报告**
   - 汇总所有分析结果
   - 生成可操作的改进建议
   - 更新 `meta_insights.md`
   - 更新 `evolution_config.md` (需用户确认)

## 输出格式

```markdown
# 🧠 元学习洞察报告

## 知识价值分析
- 总知识: N 条
- 从未应用: M 条
- 类别价值表

## 知识盲区
- [盲区列表]

## 收割策略优化
- [优化建议]

## 规则建议
- [参数调整建议]

---
所有参数变更需用户确认后生效。
```

## 安全机制

- 所有参数变更需用户确认
- 保留变更历史支持回滚
- 参数有上下限保护
