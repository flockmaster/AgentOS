# 工作流：后悔分析 (/regret-review)

本工作流回顾历史决策中评分较低的条目，帮助识别系统性错误并生成纠正建议。

## 触发方式

```
/regret-review
```

或自然语言: "回顾决策" / "分析历史错误" / "后悔分析"

## 执行步骤

1. **加载决策图**
   - 读取 `.agent/memory/evolution/decision_graph.json`
   - 统计图谱概况: 总节点数、因果链数、平均评分

2. **后悔分析**
   - 调用 `DecisionGraph.regret_analysis(min_score=-0.3)`
   - 找出 outcome_score < -0.3 的决策
   - 分析每个决策的因果影响链

3. **影响评估**
   - 对每个低分决策，追踪其 effects 链
   - 计算受影响的后续决策数量和总负面影响

4. **生成教训**
   - 从低分决策中提取模式 (反复出现的错误类型)
   - 生成反知识 (anti-knowledge) 知识卡片
   - 记录到 `decision_log.md`

5. **纠正建议**
   - 基于后悔分析，建议:
     - 需要修改的工作流步骤
     - 需要增加的门禁规则
     - 需要废弃的知识条目

6. **输出报告**

## 输出格式

```markdown
# 🔍 后悔分析报告

## 图谱概况
- 总决策: N 个
- 因果链: M 条
- 平均评分: X.XX

## 低分决策 (共 K 个)

### D-xxx: [Context]
- **选择**: [Chosen]
- **结果**: [Outcome] (评分: -0.5)
- **影响**: 影响了 N 个后续决策
- **教训**: [提取的教训]
- **纠正建议**: [具体建议]

## 系统性问题
- [归纳的共性问题]

## 生成的反知识
- k-xxx: [anti-pattern title]

---
分析完成! 共发现 K 个需要关注的决策。
```
